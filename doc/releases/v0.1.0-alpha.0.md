# Yotsuba Gantt Flutter v0.1.0-alpha.0

首个 Flutter 原生 Alpha，面向组件接入验证和大数据演示。

- 六档时间维度、任意日期范围与密集数据自动聚焦。
- 10,000 行原生虚拟滚动，网格和依赖线使用 `CustomPainter`。
- 任务拖动、时间吸附、进度、里程碑和行级视口外跳转。
- `YgGanttLinkGroup` 支持多个图表实时同步滚动和维度。
- Task Bar、任务表、边界入口和入场动画 Builder。
- Release 附带可安装 Android APK 与 SHA-256 校验文件。

APK 使用演示签名，仅用于体验和集成验证，不用于应用商店分发。
