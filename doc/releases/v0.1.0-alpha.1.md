# Yotsuba Gantt Flutter v0.1.0-alpha.1

这是面向真实消费者路径的 Flutter Alpha 更新。

## 变更

- `example/` 现在使用 pub.dev hosted dependency，不再使用仓库内 `path: ../` 依赖。
- Android APK 从 hosted dependency 演示应用构建，适合直接下载体验和验证集成。
- Release 同时提供 APK 与 SHA-256 校验文件。
- 包 API、10,000 条任务虚拟化、多图联动、日期范围和 Builder 能力保持不变。

## 安装

```yaml
dependencies:
  yotsuba_gantt: ^0.1.0-alpha.1
```

## 下载

- [Android APK 与 SHA-256](https://github.com/isla4ever/yotsuba-gantt-flutter/releases/tag/v0.1.0-alpha.1)
- [Flutter 演示源码](https://github.com/isla4ever/yotsuba-gantt-flutter/tree/v0.1.0-alpha.1/example)

APK 使用演示签名，仅用于 Alpha 体验和组件接入验证，不用于应用商店分发。
