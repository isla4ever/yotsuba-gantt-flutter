# Yotsuba Gantt Flutter v0.1.0-alpha.2

本版本完善移动端时间轴交互，并继续以 pub.dev hosted dependency 构建可安装的 Android 演示应用。

## 变更

- 新增可配置的双指分档缩放，可在六档时间维度间平滑切换。
- 单指滚动、任务拖动与双指缩放采用独立手势边界，降低误触和交互抢占。
- 维度切换后复用密集数据自动定位；关闭自动定位时保持当前视口中心。
- Android 演示新增用户主动触发的横屏沉浸入口，并优化竖屏紧凑工具栏。
- 保留 10,000 条任务虚拟滚动、依赖线、多图联动、边界跳转及 Builder 自定义能力。

## 安装

```yaml
dependencies:
  yotsuba_gantt: ^0.1.0-alpha.2
```

## 验证

- pub.dev hosted dependency 锁定至 `0.1.0-alpha.2`。
- Flutter 静态检查与组件测试通过。
- 演示应用 10,000 条任务渲染测试通过。
- Release 工作流核对实际解析版本后构建 Android APK。
